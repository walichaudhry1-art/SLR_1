Incident Summary & Timeline

At 15:13:42Z, user k.bennett launched Shipment_Manifest_9042.hta via mshta.exe (PID 5804) from C:\Users\k.bennett\Downloads. At 15:14:08Z, mshta.exe spawned an obfuscated powershell.exe process (PID 6120) with flags -NoP -NonI -W Hidden -enc.

PowerShell Script Block Logging (Event ID 4104 at 15:14:10Z) captured the decoded command downloading fleet_agent.exe from http://pkg-mirror-sync.net/dl/fleet_agent.exe (resolved to 198.51.100.88) into C:\Users\k.bennett\AppData\Local\Temp\fleet_agent.exe and executing it (PID 6340).

At 15:14:45Z, fleet_agent.exe added the HKCU Run persistence entry FleetTelemetrySvc. Between 15:15:30Z and 15:57:30Z, it beaconed over TCP/443 to 198.51.100.88. At 15:22:14Z, it attempted an SMB connection (port 445) to APP-SRV-01 (10.40.12.20), which failed with Windows Security Event ID 4625 (0xC0000022). Earlier PowerShell activity by svc_patch on WKSTN-OPS-018 and WKSTN-HR-004 at 15:04Z was verified as benign patch-compliance auditing.

Recommended Response

  • Isolate WKSTN-OPS-018 from the network via EDR containment.
  • Reset credentials and invalidate active sessions for HARBORLINE\k.bennett.
  • Block pkg-mirror-sync.net and 198.51.100.88 on the firewall, proxy, and DNS resolver; remove the FleetTelemetrySvc Run key and quarantine fleet_agent.exe and Shipment_Manifest_9042.hta.
  • Escalate to Tier 2 IR for full host forensics and verification that APP-SRV-01 was not compromised.
